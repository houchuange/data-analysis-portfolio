## 项目

**[01 · 新能源车产业链的景气传导诊断](01-nev-supply-chain/)**
`Python` `pandas` `交叉相关` `滚动窗口`

31 只 A 股标的按产业链位置分五层，1,668 个交易日，看环节之间到底有没有传导时滞。
结论是没有：日、周、月三个频段的最优滞后全落在 0 期。顺带发现链条内部的联动强度
从 2024-10 的 0.801 崩到 2026-10 的 0.109。
主文件是 notebook，跑一遍就能复现全部数字。

**[02 · Olist 电商订单的多表 SQL 分析](02-ecommerce-sql/)**
`DuckDB` `SQL` `窗口函数` `CTE`

巴西电商平台 9 张关联表、99,441 笔订单，15 条查询全部写在 `sql/` 里。
主要是想回答"97% 的客户只买一次，那增长靠什么"。答案是首购履约：
晚到 4 天的订单，平均评分从 4.04 掉到 2.11，6.67% 的晚到单造出了 32.6% 的差评。

**[03 · Cookie Cats 付费门位置的 A/B 实验评估](03-ab-testing/)**
`假设检验` `功效分析` `多重比较` `贝叶斯复核`

9 万名新玩家的随机对照实验，门槛从第 30 关推到第 40 关，7 日留存掉 0.82 pp（p=0.0016）。
交付物是一份 4 页的实验读数（memo），里面有一条我比较在意的：1 日留存的差异不显著，
但这个差异本身就小于本次实验的检出下限——"没检出"不等于"没影响"。

## 怎么读

三个项目彼此独立，各自有 README 说明数据和复现步骤。数据都是公开数据集，
其中 02 的原始 CSV（121MB）没有入库，跑一次 `scripts/fetch_data.py` 就有。

```
01-nev-supply-chain/     notebook 主导的探索分析
02-ecommerce-sql/        SQL 为主，Python 只管跑查询和出图
03-ab-testing/           实验读数（PDF）+ 统计脚本
```
